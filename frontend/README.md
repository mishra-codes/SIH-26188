# DOCSCREEN — Passport Verification Frontend

**SIH-26188 | AI-Based Fake Identity & Document Screening System**

DOCSCREEN is a frontend application designed for airport and immigration officers to screen passports using AI-assisted document verification.

The interface provides a professional verification console where officers can upload a passport image, run verification, review the risk assessment, inspect verification checks, and view previous screenings.

## Features

- Passport upload with drag-and-drop support
- Passport image preview
- AI-assisted verification workflow
- CLEAR / REVIEW / HIGH-RISK result states
- Risk score visualization
- Passenger and passport information
- OCR verification
- MRZ validation
- Expiry verification
- Tampering detection
- Face verification
- Consistency checks
- Explainable risk factors
- Verification history
- Search and status filtering
- Professional immigration officer dashboard
- Responsive interface
- Mock API mode for frontend development
- Real backend API integration structure
- Error and empty states
